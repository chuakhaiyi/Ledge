# Ledge — planning folder

**Ledge** is a sticky-notes utility for Windows that lives docked to the edge
of the screen: a thin strip of tabs that expands on hover and opens a full
note as its own small window. Everything is local — no account, no cloud,
no telemetry.

This folder is the working plan for building it from scratch, as an
original project — its own name, palette, type system, and interaction
details, distinct from any existing app in this space.

## Contents

- `docs/01-product-overview.md` — what it is, who it's for, what it isn't
- `docs/02-architecture.md` — stack choice, window management, hotkeys, data flow
- `docs/03-feature-roadmap.md` — MVP → v1 → v2 scope, cut lines
- `docs/04-data-schema.md` — note/store schema, file layout, import/export
- `docs/05-design-system.md` — palette, type, layout tokens, motion rules
- `visuals/` — HTML mockups of the core screens, built to the design system

## Suggested order

Read `01` → `02` → `04` → `05` → `03`, then open the visuals. The roadmap
makes more sense once you've seen what the app actually needs to do and
what it's built on.
